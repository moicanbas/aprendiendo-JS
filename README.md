# Performance Test
identify your skills in creating layouts with the help of
hypertext markup language (HTML), and CSS, as well as the technical knowledge
necessary to contribute effectively in real projects and work environments.
The test seeks to identify the level of your abilities to:
1. design and develop a website applying HTML and CSS.
2. Implement responsive design optimized for different devices.
3. Apply good coding practices, file organization and documentation.
4. Technically defend your solution in an individual presentation.

## Use case: 
you are a web developer who has been commissioned to create an online store, for
to display a range of products and allow visitors to contact you. This site must be
visually appealing, functional and adaptive to different devices.
